# Subliminal Audio Studio

A local-browser Streamlit app for creating loopable subliminal audio beds.

Features:

- Stack imported WAV/MP3 layers.
- Record voice affirmations per affirmation box.
- Mix selected affirmation boxes together.
- Add optional solfeggio frequencies.
- Add optional binaural beats, including a Delta Focus 10-style preset.
- Export a loopable WAV file.

Run locally:

```bash
streamlit run subliminal_studio.py
```

Deploy on Streamlit Community Cloud with:

```text
subliminal_studio.py
```

Or host directly on GitHub Pages with:

```text
index.html
```
